What it does · 它做什么

📄 Page → Markdown

One click converts the page you're on into clean, LLM-ready Markdown — headings, links, code blocks and simple tables preserved.

一键把当前网页转为干净 Markdown：标题、链接、代码块、表格完整保留。

🇨🇳 WeChat-ready

Deep extraction for WeChat official-account articles: real title, account name, publish time and the #js_content body — with lazy-loaded data-src images repaired.

微信公众号文章深度抽取：标题/公众号/时间/正文 + 懒加载图片修复。通用转 MD 工具对微信效果差，WeMD 专化处理。

📊 Token savings, quantified

See exactly how many tokens the conversion saves before you paste into an AI chat — measured with the chars/4 heuristic and labeled as such. Real measurement: a WeChat page ≈ 1.1M → 905 tokens.

粘贴给 AI 前，先看到"这次转换省了多少 token"。实测：某微信页 ≈ 111 万 → 905 tokens。

🔒 Fully local

Zero network requests from the extension. No account, no telemetry, no cloud. Conversion happens in your browser and dies with the popup unless you save it.

扩展自身零网络请求：无账号、无遥测、无云端。转换在浏览器内完成，弹窗关闭即消失，除非您主动保存。
